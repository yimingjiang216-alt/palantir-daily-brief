# 信息源规格

> 全部源于 2026-11-16 实测（从国内网络）。云端（GitHub Actions / 美国）表现可能不同，上线前需再验一次。

## 一、确定的 5 个源

| # | 源名称 | RSS 地址 | 实测条数 | 作用 |
|---|--------|---------|---------|------|
| 1 | Palantir 官方博客 | `https://blog.palantir.com/feed` | 10 | 一手产品/技术内容（Foundry / AIP / Apollo） |
| 2 | TechCrunch Palantir | `https://techcrunch.com/tag/palantir/feed/` | 20 | 财报、政府合同、CEO 表态 |

| 5 | Google News Alex Karp | `https://news.google.com/rss/search?q=%22Alex+Karp%22&hl=en-US&gl=US&ceid=US:en` | ~50 | 补 CEO 公开表态（替代失效的 X） |

## 二、每个源的特点与坑

### 1. Palantir 官方博客（一手，必留）

- 格式：标准 RSS
- 内容：工程实践、安全、AIP 能力介绍、招聘
- **坑**：偏技术宣传，不一定都算"动态"。例如 "Early Talent Hiring at Palantir" 这种招聘文，不属于交接文档要求的产品/合同/财报类
- **处理**：交给 LLM 按 prompt 的三产品线口径筛

### 2. TechCrunch Palantir 标签（二手但高质量）

- 格式：标准 RSS
- 内容：一手指名报道，财报解读、CEO 言论、竞品对比
- **坑**：TechCrunch 是媒体不是官方，可能有观点倾向
- **为什么留**：Palantir 官方 newsroom / IR 站没有 RSS（见第四节），财报和合同只能靠这类媒体覆盖

### 3. AIHOT 精选

- 格式：标准 RSS（`/rss`），**注意 API 接口已失效**
- 内容：中文精选 AI 行业新闻
- **坑**：
  - `https://aihot.virxact.com/api/public/items` 已返回 404，**不要用 API**
  - 当前 50 条里 0 条 Palantir——它是通用 AI 新闻，Palantir 被收录的概率不高
- **为什么留**：一旦命中，是质量最高的中文二手来源；成本为零

### 4. Google News Palantir（量大，噪音大）

- 格式：Google News 专有 RSS
- 内容：100 条，覆盖全球各家媒体
- **坑**：噪音非常高，实测混着这些：
  - "澳洲 Centrelink 数据如何被处理"（政府隐私争议）
  - "Palantir 在 Williams 的招聘会因抗议推迟"（社会新闻）
  - "Cathie Wood 买入 CoreWeave 卖出 Palantir"（投资操作）
  - "Palantir: High-Quality Growth Should Never Be Cheap"（投资分析）
- **处理**：全靠 prompt 里"聚焦三产品线 + 3~6 条最有价值的动态"这条约束过滤

### 5. Google News Alex Karp

- 格式：同 Google News
- 作用：Palantir CEO 的公开表态通常有新闻价值，且常被媒体转载
- **为什么加这个**：Palantir 官方 X 拿不到（见第三节），CEO 言论是重要的替代信号

## 三、X / Twitter：拿不到

实测全部失效：

| 途径 | 结果 |
|---|---|
| `rsshub.app/twitter/user/palantir` | HTTP 404 |
| `nitter.net/palantir/rss` | HTTP 410（服务已停） |
| `rsshub.rssforever.com/twitter/...` | HTTP 503 |
| `rsshub.bestblogs.dev/twitter/...` | HTTP 503 |
| `nitter.poast.org` / `nitter.privacydev.net` | 连接失败 |

**原因**：X 自 2023 年起关闭免费 API，所有 Nitter 镜像下线；RSSHub 的 twitter 路由需要付费 API key。

**替代方案**：已用「Google News Alex Karp」覆盖 CEO 表态。

**如果要恢复官方 X**：需要 X 的付费 API（Basic 档 $100/月），成本不值得。或用一个付费 RSS 服务（如 RSS.app），需额外预算。

---

## 四、Palantir 官方新闻室 / IR：没有 RSS

实测结果：

| 地址 | 返回 |
|---|---|
| `https://investors.palantir.com/rss/news-releases.xml` | HTML 网页（不是 feed） |
| `https://investors.palantir.com/rss/press-releases.xml` | HTML 网页 |
| `https://www.palantir.com/newsroom/feed/` | HTML 网页 |
| `https://www.palantir.com/feed/` | HTML 网页 |
| `https://www.palantir.com/rss.xml` | HTML 网页 |

**结论**：Palantir 的投资者关系站已改版成 JS 渲染站点，没有公开 RSS。

**后果**：交接文档要求的「财报与股价表现」「客户/政府合同」，**没有官方一手 RSS 可用**，只能靠 TechCrunch / Google News 的二手报道。

**如果一定要官方的**：需要写网页爬虫（Playwright 抓 JS 渲染页面），维护成本高，且网站改版就会失效。**当前不做，记录为已知限制。**

## 六、上线前必须重测

本地（国内网络）测通 ≠ 云端（美国）能跑。

Palantir 官方博客、TechCrunch 在美国跑会更快；但 **Google News 在国内经常超时**，云端反而应该更快。

上线第一步：把 5 个源在 GitHub Actions 里各跑一次，看实际条数。
